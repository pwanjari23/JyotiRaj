# JyotiRaj Global Company – Gruh Udyog

> **Authentic Traditional Sweets, Dry Fruits Laddus & International Export Portal**

A high-performance modern web application built for **Jyotiraj Global Company (Gruh Udyog)**. Showcases traditional Indian dry-fruit sweets, handcrafted laddus, dates khajur rolls, royal barfi, and enables retail orders, wholesale corporate gifting, and international export enquiries.

---

## ✨ Features

- **Royal Heritage Aesthetics**: Tailored palette with Royal Maroon, Antique Gold, Soft Sand, and Warm Ivory.
- **Full Product Showcase**: Detailed views for Dry Fruits Laddus, Dates Khajur Rolls, Khajur Barfi, Kids Special Laddus, and Festive Hampers.
- **Multilingual Support**: Real-time switching between English, Marathi (मराठी), and Hindi (हिंदी).
- **Multi-Currency Converter**: Toggle prices between INR (₹), USD ($), and AED (AED).
- **Interactive Quick View & Cart Drawer**: Seamless add-to-cart, pack size selection (250g, 500g, 1kg), quantity adjustments, and free shipping progress tracker.
- **Instant WhatsApp Integration**: Direct WhatsApp ordering and inquiry dispatch with pre-filled cart details.
- **B2B Wholesale & International Export**: Dedicated inquiry portals with detailed compliance, packaging, and logistics information.
- **Interactive Map & Location**: Custom interactive map view of the Gruh Udyog production facility in Badlapur, Maharashtra.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite 8
- **Icons**: Lucide React
- **Linter**: Oxlint
- **Styling**: Modern CSS Design System with CSS variables and responsive breakpoints

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/pwanjari23/JyotiRaj.git
cd JyotiRaj

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:5173/`.

### Production Build

```bash
npm run build
```

Build artifacts will be generated in the `dist/` directory.
